 Message:
 1) Registration form is not yet configured.
That's expected behavior, not a bug.

When a campaign is created, it has no form fields configured yet. You need to set up the form first:

Log in as super admin
Go to your campaign in the admin panel
Navigate to Form Builder / Form Config
Add your fields (name, email, phone, etc.)
Save.


2) Campaign is not active
The campaign status is Draft — registration only works when status is Active.

Go to the admin panel → your campaign → change status from Draft to Active, then try registering again.
